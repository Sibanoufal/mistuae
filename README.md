# Connect U

Build a functional interactive website with relevant and GEN-Z animations(light aesthetic) that university students in RIT, MDX, AUS, Herriot watt, Wollongong in UAE can use as a social platform. set the particpation or sign up requirement as student Id Photo and it works by pairing two students or a group of them (as they choose) anonymously, they text for a few minutes or day or forever with the option to disclose themselves at their choice of time. there is also options to anonymously invite or volunteer for coffee chats, event partner and project collaboration. it works like secret pen pals but the modern version of it(due to the anonymity and excitement it provides) but exclusively for existing university students in UAE. It should follow and score high on all the criteria included in the .md file attached herewith.
